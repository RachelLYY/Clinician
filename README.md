# Clinician profiles

English personal profiles for Yuwei Wu, Dandan Wang and Jia Cao, affiliated with the Second Outpatient Department, Peking University School and Hospital of Stomatology.

Static HTML and CSS. No build process or paid services required. Biographical content is based on information supplied for these pages; profiles are personal introductions, not an official hospital website.

## GitHub Pages

In repository Settings → Pages, choose **Deploy from a branch**, select **main**, select **/(root)**, and save.

- Yuwei Wu: https://RachelLYY.github.io/Clinician/yuwei-wu/
- Dandan Wang: https://RachelLYY.github.io/Clinician/dandan-wang/
- Jia Cao: https://RachelLYY.github.io/Clinician/jia-cao/

The URLs become available after GitHub Pages deployment succeeds.

Edit the corresponding `index.html` to update a profile. Shared styles are in `assets/style.css`.
